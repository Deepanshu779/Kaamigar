# KAAMIGAR (कामगार)

> **“Kaam hai? Tension mat lo. Kaamigar hai.”**  
> **“Mere ghar ka kaam hai, mujhe ek bharosemand aadmi chahiye.”**

Kaamigar is a **local-first, friendly, language-first, mobile-first, and 3D web platform** designed to connect Indian households and local shops with trusted, background-verified neighborhood workers (plumbers, electricians, carpenters, AC technicians, painters, cleaners, and mechanics).

---

## 🌟 Key Features

* **Language-First**: Seamless, instant switching between **हिन्दी (Hindi)**, **English**, and **Hinglish**. All services feature dual bilingual labels with icons (`Icon + Hindi + English`).
* **Warm & Friendly 3D Everyday Indian Home**: A low-poly Three.js interactive Indian home scene with terracotta clay roof, blue scooter, water tap with animated drops, carpenter workbench, and interactive skill hotspots.
* **Search as the Hero**: Prominent search bar with 1-tap geolocation (*Mere paas ke*) and voice search (*Bolkar batayein* with Web Speech API).
* **Nearby Kaamigar**: Realistic verified worker cards (Ramesh Kumar, Suresh Verma, Rajesh Sharma, Sunita Devi, etc.) with real distances, ratings, and direct calling/booking.
* **Simple 4-Step Process**:
  1. काम चुनें (Choose your work)
  2. कामगार चुनें (Choose a Kaamigar)
  3. बुक करें (Book)
  4. काम करवाएं (Get work done & inspect before paying)
* **Trust & Safety**: 100% Aadhaar & police verification, upfront fixed pricing (*Pehle Daam, Phir Kaam*), 7-day service satisfaction guarantee.
* **Respectful Kaamigar Onboarding**: Easy 1-tap join via WhatsApp or missed call (`1800-120-5226`), 0% commission on first 10 orders.
* **Theme Support**: ☀️ Light Mode & 🌙 Dark Mode.

## 🛠️ Tech Stack

* **Framework**: Next.js 14 (App Router)
* **Language**: TypeScript
* **Styling**: Tailwind CSS
* **3D Graphics**: Three.js
* **Typography**: Noto Sans Devanagari & Plus Jakarta Sans
* **Icons**: Lucide React
* **Animations**: Framer Motion

## 🚀 Getting Started

### Prerequisites
* Node.js 18+
* npm or yarn

### Installation

```bash
# Clone the repository
git clone https://github.com/Deepanshu779/Kaamigar.git
cd Kaamigar

# Install dependencies
npm install

# Run the development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

### Build for Production

```bash
npm run build
npm start
```
